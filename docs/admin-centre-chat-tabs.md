# Admin centre, chat tabs and global header

## Chat categories

The chat popup presents Global, Private, Groups and Communities tabs. Global is selected on first open. Communities are membership-backed groups granted by site intentions, including areas such as Workers and CS2; ordinary access groups remain under Groups.

## Admin centre

The Admin centre provides tabs for overview, accounts, default dashboards, dashboard features, groups and access, chat and communities, achievements and XP, and site settings and audit history.

## Default dashboard

Administrators can store separate desktop and mobile starting layouts. A template is applied only when an account has not initialized a personal dashboard. Existing user layouts are never overwritten. Inaccessible tiles are filtered using the member's effective permissions.

## Global header

Authenticated pages use the same generated header, navigation, role badge, message launcher, notifications and optional global notice.
